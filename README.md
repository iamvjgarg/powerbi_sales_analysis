# 📊 Sales Data Analysis – Power BI

## 📌 Project Overview
An interactive Power BI dashboard designed to analyse sales data, monitor business performance, and generate meaningful insights through data visualization.

## 📈 Analysis Covered
- Overall Sales Performance
- Revenue Analysis
- Product Performance
- Sales Trends
- Business Performance Insights

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## 🎯 Objective
To analyse sales data, track key performance indicators (KPIs), and support data-driven business decisions.
